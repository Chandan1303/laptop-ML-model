## 🔧 Deployment Steps on Render

### Step 1: Push Changes to GitHub

```bash
git add .
git commit -m "Configure Django app for Render deployment"
git push origin main
```

### Step 2: Create Web Service on Render

1. **Go to Render Dashboard**: https://dashboard.render.com/
2. Click **"New +"** → **"Web Service"**
3. Connect your GitHub repository: `https://github.com/Chandan1303/laptop-ML-model.git`
4. Configure the service:

   **Basic Settings:**
   - **Name**: `laptop-ml-predictor` (or any name you prefer)
   - **Region**: Choose closest to your users
   - **Branch**: `main`
   - **Runtime**: `Python`

   **Build & Deploy:**
   - **Build Command**: `./build.sh`
   - **Start Command**: `gunicorn laptop_predictor.wsgi:application`

### Step 3: Configure Environment Variables

In the Render dashboard, add these environment variables:

| Key | Value | Notes |
|-----|-------|-------|
| `SECRET_KEY` | (Auto-generated by Render) | Click "Generate" button |
| `DEBUG` | `False` | Must be False for production |
| `ALLOWED_HOSTS` | `.onrender.com` | Render will auto-populate your domain |
| `PYTHON_VERSION` | `3.11.0` | Python runtime version |

**Important:** After deployment, update `ALLOWED_HOSTS` to include your actual Render URL:
```
ALLOWED_HOSTS=your-app-name.onrender.com,.onrender.com,localhost
```

### Step 4: Deploy

1. Click **"Create Web Service"**
2. Render will automatically:
   - Clone your repository
   - Install dependencies from `requirements.txt`
   - Run `build.sh` (collectstatic + migrate)
   - Start the application with gunicorn

### Step 5: Verify Deployment

Once deployment completes:
1. Click on the generated URL (e.g., `https://laptop-ml-predictor.onrender.com`)
2. Test the prediction endpoints:
   - `/` - Brand prediction interface
   - `/price/` - Price prediction interface
   - `/patterns/` - Design patterns showcase

## 🔍 Deployment Configuration Details

### Build Command Breakdown (`build.sh`)

```bash
#!/usr/bin/env bash
set -o errexit              # Exit on any error

pip install --upgrade pip    # Upgrade pip
pip install -r requirements.txt  # Install all dependencies

python manage.py collectstatic --no-input  # Collect static files
python manage.py migrate --no-input        # Run database migrations
```

### Start Command

```bash
gunicorn laptop_predictor.wsgi:application
```

- Uses Gunicorn WSGI server (production-ready)
- Binds to `laptop_predictor.wsgi:application`
- Render automatically configures host and port

### Static Files Strategy

**WhiteNoise** serves static files directly from the Django app:
- No separate CDN or storage service needed
- Compresses and caches static files
- Perfect for ML apps with minimal frontend assets

### Database

- Uses SQLite (file-based database)
- Suitable for this ML prediction app (read-heavy, minimal writes)
- For high-traffic apps, consider upgrading to PostgreSQL

## 🐛 Troubleshooting

### Issue: Static files not loading

**Solution:**
```bash
# SSH into Render (if possible) or check logs
python manage.py collectstatic --no-input
```

### Issue: ModuleNotFoundError

**Check:**
- All dependencies are in `requirements.txt`
- Build logs show successful installation

### Issue: Application Error 500

**Check:**
1. `DEBUG=False` is set
2. `ALLOWED_HOSTS` includes your Render domain
3. Check Render logs for detailed error messages

### Issue: Model files (.pkl) not found

**Verify:**
- `.pkl` files are committed to git (not in `.gitignore`)
- Model loading uses `BASE_DIR` relative paths:
  ```python
  BASE = Path(__file__).resolve().parent.parent
  model = joblib.load(BASE / 'laptop_model.pkl')
  ```

### Issue: Build timeout

**Solution:**
- Large ML model files (>100MB) may cause slow builds
- Consider using Git LFS for large model files
- Current `laptop_model.pkl` is 55.98 MB (acceptable)
