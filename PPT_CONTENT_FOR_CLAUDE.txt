------------------------------------------------------------
In today’s market, purchasing a laptop is challenging because there are many brands, specs, and price ranges. Customers often find it difficult to choose a laptop that matches their budget and requirements.

This project solves that problem by developing a system that predicts:

Slide 12: Input Validation
------------------------------------------------------------
The project includes real-world validation checks to avoid unrealistic entries.

```python
def _validate_realistic_laptop_inputs(price=None, ram_gb=None, storage_gb=None, cpu_speed=None, total_sales=None):
    if price is not None and (price <= 0 or price > 500000):
        return 'Price is unrealistic for a laptop in the real market.'
    if ram_gb is not None and (ram_gb <= 0 or ram_gb > 256):
        return 'RAM size is unrealistic for a laptop.'
    if storage_gb is not None and (storage_gb <= 0 or storage_gb > 4096):
        return 'Storage size is unrealistic for a laptop.'
    return None
```

This ensures the model receives practical and meaningful inputs.
